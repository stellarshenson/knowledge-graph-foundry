# Ontology Learning and Knowledge Graph Construction from Text and Databases

- **Authors**: da Cruz et al.
- **Venue**: arXiv preprint, November 2025
- **URL**: https://arxiv.org/abs/2511.05991
- **Key contribution**: Covers ontology learning from both text and database sources, including schema evolution strategies. Addresses how ontological structures can be induced from data patterns and refined over time, with focus on type hierarchy construction from observed entity distributions.
- **Relevance to H5g**: Supports the conservative evolution approach - building hierarchy entries only when cross-type patterns meet minimum document thresholds. The schema evolution perspective validates evolving resolution rules across runs rather than fixing them upfront.
