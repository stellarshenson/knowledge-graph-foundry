# Research Concepts

Foundational concepts underlying KGF architecture, extracted from design research conversations.

- [Ontology Lifecycle](concept-ontology-lifecycle.md) - curing/stabilization phases and adaptive resolution guides that evolve from accumulated evidence
- [Bayesian Resolution](concept-bayesian-resolution.md) - posterior-based entity resolution with multi-channel evidence fusion and positive evidence accumulation
- [Decision Architecture](concept-decision-architecture.md) - two-layer adjudication (statistical + LLM reasoning), calibration, contextual triggers, and epistemic loop prevention
- [Pipeline Governance](concept-pipeline-governance.md) - FSM lifecycle states and graph metanode control plane with lease-style locking
- [Architectural Positioning](concept-architectural-positioning.md) - innovation classification, agent escalation boundaries, and design signature
