# Advantages

Findings from an external evaluation run on 2026-09-13, in which KGF was assessed against HippoRAG 2, Microsoft GraphRAG, LightRAG and graphify as the engine for a private Polish-language legal-evidence corpus: 729 documents, 2.07 GB, mixed PDF / DOCX / audio / image, arriving in monthly batches over four years, where the required output is a claim traceable to a quotation, a document and a page. The advantages below are the ones that decided the comparison. Each names the mechanism and where it lives, so the claim is checkable against the code rather than the prose.

The evaluation corpus is not distributed with this project and is not referenced further.

## Advantages that decided the comparison

- **The indexing unit is the assertion, not the entity** - `propositions_enabled` defaults on, propositions are embedded into their own index, seeded into PPR (`proposition_seeding`), and split above 300 tokens (`settings.py`, `QuestionSettings` / retrieval block). A domain whose target relation holds between two statements rather than two entities is served directly. GraphRAG's equivalent claims/covariates pass is off by default; LightRAG and HippoRAG 2 have no assertion tier at all
- **A multilingual entailment head is already in the stack** - `MoritzLaurer/mDeBERTa-v3-base-mnli-xnli`, pinned in the identity-calibration artifact and loaded by `resolution/identity_stack.py`. It is used narrowly today, to veto an entity merge above `nli_veto_threshold` 0.5, but it is a general XNLI-trained adjudicator covering the non-English languages an evaluator is likely to arrive with. No other system in the comparison ships one
- **Non-English corpora are a configuration change, not a port** - the passage channel defaults to `BAAI/bge-m3` on `local-gpu` (`ChannelEmbedding`), which is multilingual by construction. The three alternatives assume English embeddings throughout, so a Polish corpus is a rewrite for them and a config edit here
- **A fully local inference path exists and is measured, not aspirational** - `LLMSettings.engine` takes `local-gpu` or `claude-cli` beside `frontier`; entity embeddings take `e5-local` (`intfloat/e5-base-v2`, 109M, 768-dim), recorded at statistical parity with Bedrock Titan under `R47-H582b`. A confidential corpus can be ingested end to end without a third-party API call. The NEW-GRAPHS-ONLY caveat is documented in `extraction/embeddings.py`: the entity index is pinned to the (provider, model) dimension, so the provider is chosen before the graph is built, never swapped onto a live one
- **Provenance is carried to the document and the chunk** - per-entity source documents and chunks, an event log, and per-document coverage certificates with a gap ledger. For an evidence domain this is the difference between a usable answer and an unusable one: GraphRAG offers source references inside a summary, LightRAG chunk references, HippoRAG 2 none
- **Bitemporal invalidation is non-lossy, so the consumer can be inverted without touching the store** - `graph/temporal.py` reconciles a superseding fact by setting `valid_to` on the prior edge and never deletes it, with a `_HISTORY` read returning the full series (the Graphiti/Zep model). Default reads return current edges and the invalidation count feeds a drift alarm at `contradiction_rate_threshold` 0.2. A domain that values the superseded statement more than the current one - litigation being the clear case - is served by changing what consumes the count, not by changing how facts are stored. The mechanism was built for maintenance and turns out to be a retrieval primitive
- **Ontology growth is bounded by a statistical gate rather than a heuristic** - the curing FSM (`EMPTY → INITIALIZING → CURING → STABLE ↔ RECURING`) fires on JSD < 0.02, Chao1 coverage > 0.95, entropy delta < 0.01 and a Good-Turing missing-mass UCB ≤ 0.05 at z = 1.64, over at least 3 documents. On a heterogeneous corpus - correspondence, transcripts, filings, institutional letters in one tree - the failure mode that kills untyped systems is unbounded type proliferation, and this is the only mechanism in the comparison that addresses it with evidence rather than a cap
- **Identity is decoupled from type** - identity derives from the normalized name and types are multi-label attributes, so a person occupying several roles across a corpus is one node carrying several labels rather than several nodes to be reconciled later. In an adversarial-document domain the same individual routinely appears in four roles; every alternative in the comparison would fragment them
- **Ingest is incremental and restart-safe against on-disk state** - lifecycle state, ontology, calibration and buffers persist in a graph control metanode, and ingest resumes idempotently after process death (recorded most recently mid-ingest at document 966 of 1,000). A corpus that arrives in batches for years never pays a full rebuild. The incumbent it was compared against required a full re-merge, re-cluster and wipe-and-push per batch
- **Context cost is a certified lever, not a tuned threshold** - the escalation gate is fitted by conformal risk control with a distribution-free E[miss] ≤ 0.08 certificate, reaching full composed recall at roughly a quarter of static rendering cost. An evaluator can state what the gate costs in recall, which a tuned cut-off cannot support
- **The failure register made the evaluation possible in an afternoon** - `docs/recall-failure-modes.md` (RFM-1..9), the defect log, and an append-only ledger of 538 pre-registered hypotheses with refutations promoted rather than buried. Assessing a system is normally dominated by discovering what it does badly; here that was read rather than measured, and the residual risks were quotable on first contact

## Gaps the same evaluation surfaced

Recorded here because the project's own doctrine is to promote refutations as knowledge, and because an evaluator meeting these three will meet them in the first hour.

- **No admission gate on text extraction** - `ingest/readers.py` parses a PDF with pymupdf4llm unioned with pypdf and ingests whatever returns. A scanned page returns near-empty text and enters the graph silently as an empty document. In the evaluation corpus 17.6% of PDFs carry no text layer, so the gate is not an edge case
- **No image path** - `UNSTRUCTURED_EXTENSIONS` is `{pdf, docx, html, htm, md, txt}`. Image-only evidence is skipped rather than routed to a vision model and a sidecar
- **Extraction carrier recall remains the dominant risk** - 76.8% mean on a single pass with high run-to-run variance, guided repair saturating near 85%. The project registers this itself; it is restated here because in a domain where a missed statement is a missed finding it sets the ceiling on everything above

## Scope of these findings

Every headline number this project reports was measured on the 2WikiMultihopQA ladder, which is English Wikipedia multi-hop QA. The advantages above are architectural and hold independently of that; the performance figures do not transfer to another language or domain without being re-measured there.
