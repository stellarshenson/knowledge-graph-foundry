**PANGU: Don't Generate, Discriminate - A Proposal for Grounding Language Models to Real-World Environments (2023)**

Most grounded language understanding systems ask an LM to directly generate an executable plan (a SPARQL query, an API call sequence), forcing the LM to carry the full burden of grammaticality, faithfulness, and controllability. Pangu inverts this: a symbolic agent enumerates valid candidate plans by walking the environment's actual structure, and the LM is reduced to a discriminator that scores plan plausibility. On knowledge base question answering (KBQA), a **BERT-base** discriminator lifts GrailQA F1 from 31.8% to **48.2%** on the compositional GraphQ split, and scaling to T5-3B reaches **81.7% F1** on GrailQA overall - state of the art at publication with no larger generative LM needed.

**Key mechanism**
- Symbolic agent incrementally grows a partial plan by exploring only environment-valid next steps (e.g., legal KB relations from the current entity) - the search space is pruned by construction, so the LM never has to learn syntax or schema constraints
- LM is a pure scorer: given a natural-language question and a fully-formed candidate plan, output a plausibility score; no plan tokens are generated by the LM at all
- Best-first / beam search over the agent's expansion tree, ranked by LM scores, replaces autoregressive decoding of the plan itself
- Because the discriminative objective is far easier than generation, the model converges in as few as two epochs, trading i.i.d. overfitting for stronger non-i.i.d. and zero-shot generalization
- Same protocol extends to few-shot in-context learning: Codex scores candidate plans from the agent without any fine-tuning at all

**Main findings**
- GrailQA (BERT-base): 79.9% F1 overall, new SOTA at the time; T5-3B pushes overall to **81.7% F1**, 78.5% on the zero-shot split
- GraphQ (compositional, harder distribution shift): BERT-base jumps prior SOTA from 31.8% to **48.2% F1**; T5-3B reaches 62.2% F1
- WebQSP: competitive with DecAF despite DecAF using a 3B-parameter generative LM against Pangu's BERT-base
- In-context learning with Codex (no fine-tuning): 56.4% EM / 65.0% F1 at 1000-shot on GrailQA - first demonstration that KBQA is tractable few-shot when the LM only discriminates
- Monotonic scaling: larger LMs (BERT-base -> T5-base -> T5-large -> T5-3B) improve results across every dataset and split with no exceptions observed

**Key takeaways**
- Discrimination is a strictly easier learning problem than generation when the target space is enumerable by a symbolic agent - this converts an unconstrained generation problem into a ranking problem, which is both more sample-efficient and more robust to distribution shift
- The pattern generalizes beyond KBQA to any grounded task where valid next actions can be symbolically enumerated (tool use, API orchestration, code execution) - the LM's job shrinks to "does this look right," not "produce something valid"
- Compositional/zero-shot generalization benefits disproportionately, because the discriminator never has to memorize surface generation patterns for structures it hasn't seen

**Relevance**
- Directly informs R50's typed/topology retrieval question: if KGF can enumerate valid candidate subgraphs or paths via graph topology constraints, a discriminative scorer (not a generative query-writer) may be the more robust retrieval-time architecture, especially for compositional multi-hop queries
- The "search then score" split maps onto graph-constrained candidate generation followed by LLM-judge scoring, a pattern KGF already uses elsewhere in the pipeline
